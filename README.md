# Dual-Wavelength PDPT Calibration — A Simulation Study

> Physics-grounded simulation of a photodiode-based Planck thermometry (PDPT) calibration
> pipeline, built to explore how to correct for detector/process errors that a single
> physics equation can't capture — and a record of finding and fixing a data leakage bug
> in an earlier version of this work.

**TL;DR (English):** This repository documents a calibration-modeling exercise built on top
of a real capstone project (a dual-wavelength emissivity-independent temperature sensor for
laser processing, Chonnam National University). No real measurement data is included or
claimed — the earlier version of this notebook had a data leakage bug (an input feature was
generated by interpolating from the target itself), and this version rebuilds the data
generation with correct causal direction, adds an automated leakage-audit check, and reports
results under a fair, feature-matched comparison. See `pdpt_calibration_simulation.ipynb` for the full analysis and
[the executed Kaggle version](https://www.kaggle.com/code/ericwittjr/dual-wavelength-pdpt-calibration-a-simulation-stu)
for rendered plots.

---

## 배경

전남대학교 기계공학부 캡스톤디자인(기업연계형)에서 레이저 공정 중 표면 온도를 실시간으로
측정하는 PDPT(Photodiode-based Planck Thermometry) 시스템을 개발했다. 이 시스템은 두 파장의
복사 강도 비를 이용해 방사율(emissivity) 변화의 영향을 상쇄하는 방식으로 동작한다.

실험 도중 레이저 장비 고장으로 실측 데이터가 불완전하게 확보되었고, 이를 보완하기 위해
문헌 데이터와 물리식을 바탕으로 다변수 캘리브레이션 모델링을 시도했다.

## 이전 버전의 문제

초기 버전은 캘리브레이션 모델의 R²이 1.0에 근접하게 나왔다. 물리 계측 데이터에서 잔차가
사실상 0이라는 것은 모델이 잘 맞았다는 뜻이 아니라 구조적 결함의 신호라고 판단해 원인을
역추적했다. 확인 결과, 입력 피처로 쓴 전류값이 예측 대상인 온도값으로부터 보간(`np.interp`)되어
생성된 값이었다 — 사실상 타겟의 변형에 불과한 피처였다. **데이터 리키지**였다.

## 이번 버전에서 고친 것

1. **인과 방향 재설계** — 전류를 독립 변수로 생성하고, 참 온도를 그 결과로 계산하도록 순서를 바꿈.
   단, 방향만 바꾸는 것으로는 부족함 — 전류에서 온도로 가는 경로가 결정적 함수이면 리키지는
   그대로 남기 때문에, 접촉저항 편차·공정 노이즈 같은 **관측 불가능한 물리적 산포**를 명시적으로
   추가해 완전한 역산이 불가능하도록 구성함.
2. **리키지 자동 감사 함수** — 각 피처가 단독으로 타겟을 설명하는 정도를 비모수적으로 측정해
   임계값을 넘으면 경고하는 `leakage_audit()` 함수를 작성. 클린 데이터에서는 통과하고, 이전
   버전의 생성 방식을 그대로 재현했을 때는 실제로 감지하는지까지 검증함.
3. **공정한 성능 비교** — 이전 버전은 피처 1개짜리 선형회귀와 피처 4개짜리 XGBoost를 비교해
   "17배 개선"이라고 결론지었는데, 그 차이의 대부분은 알고리즘이 아니라 피처 개수 차이였다.
   이번에는 물리식 단독 역산 / 선형 다변수 / XGBoost를 **동일한 입력**으로 비교함.
4. **부호 오류 수정** — 캡스톤 보고서 식 (9)의 분자 부호가 실제로는 온도가 음수로 나오는
   오류가 있어, Wien 근사에서 직접 재유도한 형태로 대체함.
5. **정직한 라벨링** — 실측 데이터가 없다는 것, 결과가 검증된 시스템 성능이 아니라는 것을
   본문 첫 셀에 명시함.

## 결과 (시뮬레이션 기준, 실측 아님)

| 방법 | 입력 | RMSE [K] | R² |
|---|---|---|---|
| A. 물리식 단독 역산 | 복사비만 | 62.3 | 0.937 |
| B. 선형 다변수 | 4개 피처 | 39.9 | 0.974 |
| C. XGBoost | 4개 피처 (A와 동일 조건) | 22.3 | 0.992 |

물리식 단독 역산의 잔차는 검출기 응답 불일치로 인한 계통 오차 때문에 한쪽으로 치우쳐 있고,
다변수 정보를 추가하면 이 치우침의 상당 부분이 보정된다. 이 개선의 대부분은 다변수 정보
자체에서 오며, 알고리즘(선형 vs XGBoost)의 차이는 상대적으로 작다.

## 이 저장소가 말하지 않는 것

- 실측 데이터를 포함하지 않으며, 위 수치는 실제 계측 시스템의 성능이 아니다.
- 오차 모델의 파라미터(검출기 이득 불일치, 드리프트 계수 등)는 동정된 값이 아니라 가정값이다.
- 따라서 이 결과는 보정 전략을 세우기 위한 사전 검토이며, 확정된 캘리브레이션 곡선이 아니다.
